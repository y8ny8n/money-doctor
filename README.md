# 💰 머니닥터 (MoneyDoctor) - 구글 애드센스 고수익 특화 웹 툴킷

대한민국 직장인, 프리랜서, 자영업자를 위한 **2026 연봉 실수령액·실업급여·퇴직금·대출이자 올인원 금융 계산기** 웹사이트입니다.

구글 애드센스(Google AdSense) 고단가 광고(CPC 1위 금융·대출·세무) 매칭과 빠른 승인(애드고시 통과)을 목적으로 기획·제작되었습니다.

---

## 🌟 주요 기능

1. **2026 연봉 실수령액 계산기**
   - 2026년 최신 4대보험(국민연금, 건강보험, 장기요양보험, 고용보험) 요율 및 상하한액 반영
   - 국세청 간이세액표 및 비과세 식대(월 20만원 한도), 부양가족/자녀 세액공제 알고리즘
   - Chart.js 기반 공제 항목별 시각화 도넛 차트 및 결과 클립보드 복사
2. **2026 실업급여(구직급여) 모의 계산기**
   - 연령 및 고용보험 가입기간별 법정 소정급여일수(120~270일) 자동 산출
   - 2026년 기준 1일 상한액(66,000원) 및 최저임금 연동 하한액(63,104원) 자동 보정
3. **법정 퇴직금 & IRP 세금 계산기**
   - 입사/퇴사일 기준 재직일수 계산 및 3개월 평균임금, 상여금, 연차수당 반영
4. **대출 이자 및 월 상환액 계산기**
   - 원리금 균등상환, 원금 균등상환, 만기일시상환 방식 비교 지원
5. **프리랜서 3.3% 원천징수 계산기**
   - 사업소득세 3% + 지방소득세 0.3% 원천징수 실수령액 및 5월 종합소득세 환급 팁 제공
6. **애드센스 승인 전용 법적 필수 페이지 (모달 탑재)**
   - 개인정보처리방침 (쿠키 및 맞춤형 광고 동의 안내)
   - 이용약관 (금융 면책 조항)
   - 서비스 소개 및 공공데이터(국세청, 건보공단 등) 출처 명시
   - 문의하기 안내

## 🚀 1단계: 무료 웹사이트 배포하기 (서버 비용 0원)

본 프로젝트는 순수 정적 웹(Static Web)으로 제작되어 서버 비용이 전혀 들지 않으며, 아래 2가지 방법 중 하나로 3분 만에 전 세계에 무료 배포할 수 있습니다.

### 방법 A: Vercel 배포 (가장 추천 ⭐️⭐️⭐️)
1. [GitHub](https://github.com/)에 로그인 후 새 Repository 생성 (`money-doctor`)
2. `d:\docker\money-doctor` 폴더의 파일들을 업로드 (git push)
3. [Vercel](https://vercel.com/) 가입 후 `Add New Project` 클릭
4. 올린 GitHub 저장소를 선택하고 `Deploy` 버튼 클릭
5. **30초 후 나만의 무료 사이트 주소(`https://xxxx.vercel.app`)가 생성됩니다.**

### 방법 B: Cloudflare Pages / GitHub Pages
- GitHub 저장소 설정(Settings) -> Pages 메뉴에서 `main` 브랜치를 선택하면 무료로 즉시 배포됩니다.

---

## 🌐 2단계: 커스텀 도메인 연결 (애드센스 승인율 3배 UP)

구글 애드센스는 무료 서브도메인(`*.github.io`, `*.vercel.app`)보다 **독립 도메인(`*.com`, `*.kr`, `*.me` 등)**을 등록할 때 승인 속도와 합격률이 압도적으로 높습니다.

1. **도메인 구매**: 가비아, 후이즈, 호스팅케이알 또는 Cloudflare Registrar에서 연 1~1.5만 원 수준의 도메인(예: `moneydoc.kr`, `my-salary.com` 등) 구매
2. **Vercel / Cloudflare 설정**: `Settings` -> `Domains`에서 구매한 도메인 입력 후 DNS 레코드 연결

---

## 🔍 3단계: 구글 서치콘솔(Google Search Console) 등록

구글 검색 결과에 사이트를 노출시키고 트래픽을 모으기 위한 필수 단계입니다.

1. [Google Search Console](https://search.google.com/search-console)에 접속하여 배포된 사이트 URL 등록
2. 소유권 확인 완료 후, 좌측 메뉴의 **Sitemaps(사이트맵)** 클릭
3. `sitemap.xml` 입력 후 제출
4. 며칠 내로 구글 로봇이 사이트를 수집하여 구글 검색에 노출되기 시작합니다.

---

## 💵 4단계: 구글 애드센스 신청 및 광고 코드 삽입

사이트에 하루 수십~수백 명의 방문자가 발생하기 시작하면 구글 애드센스를 신청합니다.

1. [Google AdSense](https://adsense.google.com/) 접속 후 사이트 등록
2. 발급받은 `<script async src="https://pagead2.googlesyndication.com/..."></script>` 코드를 `index.html`의 `<head>` 태그 안에 삽입
3. 루트 디렉터리의 [ads.txt](file:///d:/docker/money-doctor/ads.txt) 파일에 본인의 `pub-XXXXXXXXXXXXXXXX` 퍼블리셔 ID 입력
4. 승인이 완료되면 `index.html` 내의 `.ad-placeholder` 위치에 생성한 단위 광고 코드를 넣거나 '자동 광고(Auto Ads)'를 활성화합니다.
